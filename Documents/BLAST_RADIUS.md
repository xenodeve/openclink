## 2. ลำดับที่ต้องลง

**หลักเดียวที่กำหนดลำดับ — สามข้อในรายการนี้คือเครื่องมือวัด และการลงของที่เปลี่ยนพฤติกรรมก่อนเครื่องมือวัดทำให้ประเมินผลไม่ได้**

| คลื่น | ข้อ | เหตุผล |
|---|---|---|
| **0** | **9** | ไม่มีข้ออื่นในรายการที่คนติดตั้งตามเอกสารจะมองเห็น เพราะเขากำลังรัน upstream อยู่ · ทุกการวัดบนเครื่องที่ตั้งค่าด้วย `run-server.sh` ก่อนข้อนี้ลง คือการวัดโปรแกรมคนละตัว · ไม่แตะ Python ไม่แชร์ไฟล์กับใคร จึงไม่มีเหตุผลให้รอ |
| **1** | **1** แล้ว **2** และเอา enum ของ `model` จากข้อ 8 มาด้วย | ข้อ 1 เป็นบรรทัดเดียวและคืนอำนาจตัดสินใจให้ host · ข้อ 2 รูปแบบพังครั้งแรกจะทำให้ clink ล้มทุก call — การรับความล้มเหลวนั้น **หลัง** host ถูกติดอาวุธให้ถามแล้ว คือความต่างระหว่างความล้มเหลวที่มองเห็นกับการอนุมัติอัตโนมัติเงียบๆ · enum ของ `model` อยู่คลื่นนี้เพราะเป็น **การบังคับเดียวที่มีอยู่** ต่อช่องโหว่ argv injection บน Windows เนื่องจาก `refuse_unservable` ไม่ทำงานเมื่อไม่มี config ไหนประกาศ `model_catalog` |
